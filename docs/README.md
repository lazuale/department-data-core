**Порядок знакомства:** моделирование → [учебный пример](practical-modeling-example.md) → архитектура → именование.

Учебный пример содержит диагностические SQL-запросы и разбор ложной декомпозиции. Запросы разделов 8–9 теперь проверены на синтетических данных PostgreSQL 18.6; ожидаемые результаты отделены от фактических. [Протокол проверки](https://github.com/lazuale/department-data-core/actions/runs/38214426921).

Опыт T1/T2 **уже проведён** на изолированном PostgreSQL 18.6. Фактический вывод и ограничения описаны в [протоколе](practical-modeling-example.md#103-протокол-проведённого-испытания).

Пример не входит в нормативные правила и не устанавливает свойства реальных источников. Порядок доказательства решений описан в [архитектурном каноне](data-core-architecture-standard.md#порядок-проверки-решений). Старые реализации не служат основанием для модели.
