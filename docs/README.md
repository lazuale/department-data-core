**Порядок знакомства:** моделирование → [учебный пример](practical-modeling-example.md) → архитектура → именование.

В примере есть диагностические SQL-запросы и разбор ложной декомпозиции. Опыт T1/T2 **уже проведён** на изолированном PostgreSQL 18.6, а фактический результат и ограничения вывода приведены в [протоколе](practical-modeling-example.md#103-протокол-проведённого-испытания). Запросы из разделов 8–9 ещё не запускались в PostgreSQL: для них приведены ожидаемые результаты.

Пример не входит в нормативные правила и не устанавливает свойства реальных источников. Порядок доказательства решений описан в [архитектурном каноне](data-core-architecture-standard.md#порядок-проверки-решений). Старые реализации не служат основанием для модели.
