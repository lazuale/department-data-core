# department-data-core

`department-data-core` (DDC) — архитектура единого ядра данных на PostgreSQL. Проект описывает, как объединять сведения из разных источников в общую предметную модель и разделять хранение входа, работу с данными и аналитическое представление.

Модель строится вокруг смысла данных: сущностей, фактов и отношений. Она не копирует структуру конкретного Excel-файла, CSV-выгрузки или API. Это помогает сохранять общую идентичность и связи при изменении источников.

## Документация

Начните с [архитектуры базы данных](docs/data-core-architecture-standard.md). В [A03](docs/data-core-architecture-standard.md#a03-схемы-и-зависимости) приведены обзорная схема и назначение девяти схем PostgreSQL.

Полный канон находится в `docs/` и состоит из трёх частей:

1. [Архитектура базы данных](docs/data-core-architecture-standard.md) — размещение данных, границы схем и SQL-интерфейсы.
2. [Моделирование данных](docs/data-modeling-standard.md) — смысл строк, ключи, отношения и целостность.
3. [SQL naming](docs/naming-convention.md) — имена объектов PostgreSQL.
