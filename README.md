# Department Data Core

DDC — правила проектирования реляционных моделей в PostgreSQL. Репозиторий описывает, как обосновывать смысл данных, ключи, связи и ограничения. Здесь нет готовой модели для всех источников, приложения или обязательного набора таблиц.

## Документы

1. [Моделирование данных](docs/data-modeling-standard.md) — с чего начинать, как проверять ключи, зависимости и ограничения.
2. [Разбор на примере](docs/practical-modeling-example.md) — проверка гипотез по данным, диагностический SQL и отдельный опыт с конкурентной записью.
3. [Архитектура базы данных](docs/data-core-architecture-standard.md) — границы предметных и технических данных, назначение схем, правила доступа.
4. [Именование объектов](docs/naming-convention.md) — требования к SQL-именам.

Пример основан на вымышленных предметных условиях. При работе с настоящим источником его ключи и таблицы не переносят: сначала устанавливают собственные предметные правила и проверяют их.
